## 适合谁

| 场景 | 典型用户 | Tally 怎么帮 |
|------|---------|-------------|
| 跨境贸易 | 抖店 + 批发双渠道商家 | 多币种、补货预测、动态定价、多渠道分配 |
| 本地零售 | 五金店、百货、夫妻店 | 万级长尾 SKU、规格模糊匹配、熟客记忆、日报整理 |
| 混营企业 | 跨境 + 零售并行 | 两套能力并集，按需折叠高级字段 |
