# 常见问题

## 账号

- **一个账号通用所有产品吗**：是。统一账号体系，注册一次登录所有产品（API、Lucrum、Switch、Creator 等），共享钱包余额和订阅计划。
- **改密码**：登录 [identity.lurus.cn](https://identity.lurus.cn) → 账号设置 → 安全 → 修改密码。
- **忘记密码**：登录页点击「忘记密码」，注册邮箱收重置链接。
- **删除账号**：联系 [support@lurus.cn](mailto:support@lurus.cn) 注销，所有数据（API Key/鹿贝/交易记录）永久删除不可恢复。
- **第三方登录**：GitHub、Google OAuth，账号设置中绑定/解绑。

---

## 订阅与计费

- **升级/降级套餐**（登录 [identity.lurus.cn](https://identity.lurus.cn) → 订阅管理 →「变更套餐」）：升级立即生效按比例补差价；降级下个计费周期生效。
- **订阅到期**：自动降级 Free，API Key 仍有效但受 Free 配额限制，数据保留随时续费恢复。
- **年付 vs 月付**：年付 8 折（≈免费用 2.4 个月）；年付期间不可降级但可升级。
- **团队加成员**（Enterprise）：管理后台 → 团队 → 邀请成员 → 输邮箱发邀请 → 成员接受加入 → 可为每成员分配独立 API Key 和配额。

---

## 鹿贝

- **用途**：支付超订阅配额的 API 调用、订阅 Lucrum 付费策略、享 VIP 折扣。
- **过期**：购买的永久有效；活动赠送可能有有效期，以活动规则为准。
- **提现**：充值购买的未使用可退款；Lucrum 策略收入结算的鹿贝可提现银行卡。
- **查余额/记录**：登录 [identity.lurus.cn](https://identity.lurus.cn) → 钱包，查看当前余额、收入明细（充值/奖励/策略收入）、支出明细（API 消费/策略订阅）。

---

## 支付

支付方式：Stripe（信用卡/借记卡，全球）、Creem（加密货币）、Epay（支付宝/微信，中国大陆）。

- **付款未到账**：通常 1 分钟内确认；超 5 分钟未到账则检查支付平台是否扣款、查邮箱确认邮件、联系 [support@lurus.cn](mailto:support@lurus.cn) 提供支付订单号。
- **申请发票**：管理后台 → 账单 → 申请发票（增值税普通/专用），通常 1 个工作日内发邮箱。

---

## 安全

- **数据安全吗**：全程 HTTPS（TLS 1.3）；密码 bcrypt 加密存储；支付走 PCI DSS 合规第三方；API 调用内容不存储（仅记元数据用于计费）。
- **API Key 被盗用**：立即控制台禁用该 Key → 创建新 Key → 检查调用日志确认异常消费 → 联系客服处理异常扣费。
